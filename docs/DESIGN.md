# 设计说明与踩坑记录

> 这份文档只记**为什么这么做**和**踩过的坑**。怎么跑起来看 `README.md`。

---

## 1. 世界坐标 + 摄像机

```
世界层（.world）宽 worldW，高 worldH
   ├── 背景图
   └── 角色：petX（世界坐标），脚底在 groundY
摄像机 camX ∈ [0, worldW - viewportW]
```

角色在**世界坐标**里移动，摄像机是它的一个横向窗口。`camX` 跟着 `petX` 走，
撞到两端就停 —— 于是角色跑到墙边时，摄像机会停住，她继续在屏幕上滑。

为什么不用「固定背景 + 角色在屏幕里滑动」：后者角色会滑出画面被切掉一半。

**可走范围要按「摄像机跟得动」来收**：如果 `walkableX` 贴着世界边缘，
角色走到边上时摄像机已经顶到极限，画面就不动了（表现是「向右跑背景不动」）。
所以世界宽比提到 1.6 倍，可走范围收进中间那段。

角色半宽按**实测**取 `boxW * 0.2`（素材里角色占画布宽 33.4%，半宽 0.17，再留 3% 呼吸位）。
取大了她会被挡住，取小了她会半个身子出画。

## 2. 播放器：双缓冲 + 平台回落

两个 `<video>` 叠着，一个播当前动作，另一个预载下一段。切换时交换 —— 避免 `src` 重设导致的
「卸载 → 解码 → 首帧」黑一下。

**iOS 是个坑**：Safari 不认 VP9 的 alpha 通道，webm 播出来是黑底。
上游另发了同名 HEVC-alpha `.mov`（`scripts/fetch-mov.sh` 拉），按能力探测切换：

```js
canPlayType('video/quicktime; codecs="hvc1"')
```

**别用 UA 判断** —— Chromium 能解析 HEVC 容器却解不了码，用 UA 判断会一路 `ERR_ABORTED`。
探测失败一次就永久记住，不要每个动作都试一遍。

---

## 3. 命中区：视频画布 ≠ 角色本体

视频是 640×360，但角色只占：

- 横向 **33.3% ~ 66.7%**（正好居中，半宽 = 容器宽 0.17）
- 纵向 **16.7% ~ 91.5%**（脚底在 91.5%）

如果命中区用 `inset: 0` 铺满整个容器，四边的透明留白也成了「她」——
鼠标停在旁边的门上光标还是 `grab`，在空地按住能把人隔空拖走。

所以**视觉层与命中层拆开**：`.pet-inner` 放 video，`.pet-hit` 单独定位到角色本体，
四边各留 ~3% 余量给头发、尾巴和手指误差。

> 另一个坑：`.pet-hit` 上的 `clip-path` 会把**同一元素里**的 video 一起裁掉。
> 拆层是唯一解。

---

## 4. 阴影与「飘」

阴影不能贴在容器底边（`bottom: 0`）—— 那比脚底低 8.5% 容器高，看起来像悬空。
按实测脚底位置（91.5%）算，两层阴影 + `multiply` 混合。

---

## 5. 走动：脚动了才走

素材里的走动动作是「原地准备 → 跑 → 收尾站定」三段式，位移 ≈ 0，全靠代码平移。
如果一触发就立刻平移，看起来是「脚没动人在滑」。

解法：按 `leadSec` / `tailSec` 延迟启动、按时停止。位移量按**身高/秒**算，不用上游的
`minDist/maxDist`（那是 462px 小画布口径，换算到大屏只剩 0.12 身高/秒，像在挪）。

```
距离 = 速度 × 角色身高 × 可跑时长
```

三个走动动作速度分别 0.18 / 0.5 / 0.62 —— 小碎步真小、奔跑真远。

**朝向要在 `onAnimStart` 之后取**：之前算好会在翻面后仍用旧值，表现是「撞墙后倒着跑」。

---

## 6. 拖拽

拖拽也走摄像机跟随，不是「拖房间」。跟手用 rAF 追目标，**每个 `pointermove` 都要确保 rAF 在跑** ——
追到目标就停、后续 move 没重启 rAF，表现是「拖两下就不跟手了」。

拖到房间尽头后角色继续在屏幕上滑，摄像机不动。

---

## 7. 昼夜

`scene/daylight.ts`：`SUNRISE = 6.5`、`SUNSET = 18.5`（本地时间），每分钟对一次系统时钟。

**不要「算好毫秒再 setTimeout」** —— 页面连开几天，休眠、锁屏、显示器断电都会让计时器停摆或漂移。
每分钟重算一次，醒来最多晚 60 秒，但永远不会错到「大中午还黑着灯」。

切换用两张 `<img>` 叠着只改 `opacity`（0.9s 交叉淡入）。**绝不换 `src`** ——
换 src 会经历卸载 → 重新解码 → 首帧，中间必然黑一下。

**角色必须跟着压暗**（`.stage.night .pet-inner { filter: brightness(0.8) }`）：
素材是白天打光的，不压就会像自带补光灯从夜里浮出来。
滤镜要加在 `.pet-inner` 而不是 `.pet-layer` —— 气泡也挂在 `.pet-layer` 里，压暗会把字一起弄灰。

## 8. 天气

雨只下在**窗外和玻璃上**，屋里不会淋到 —— 每个房间在 `scenes.json` 里定义 `rain.windows`
（矩形区域）与 `rain.ground`，粒子只在这些区域里生成。

雪同理。切到「雪」但房间没有 `snowImage` 时，用白天图去色 + 提亮兜底。

---

## 9. 面板：平时隐身

右上角 `≡` 默认 `opacity: 0; pointer-events: none`，**点一下屏幕才浮出**，4.5 秒不碰自动收；
点面板外也收。常驻显示太抢眼。

面板入场动画只做「向上 + 淡入」，**不做横向位移** —— 早期版本带左移，看起来像面板在跳。

## 10. 壁纸 / 本地文件模式

`localStorage` 在 `wp://` 或 `file://` 下会抛 `SecurityError`。
如果这个调用写在 Promise 的 `.then()` 里，一抛就掉进 `.catch()` → 整页「场景加载失败」。

所以统一走 `util/storage.ts`：写入同时存内存，读写失败退回内存。
壁纸里记不住偏好，但不会白屏。

同理 `net/ws.ts`：非 `http(s)` 协议直接不连 WS，否则无效地址会走进无限重连，
console 每十几秒报一次错。

## 11. 素材工程的三条事实

实测，不是猜的：

1. 视频画布 **640×360**，角色占高约 75%，**脚底在画布 91.5%** 处
2. 角色横向占 **33.3% ~ 66.7%**（正好居中），半宽 = 容器宽的 0.17
3. 每段动作**首尾帧都是标准正面站立**，总位移 ≈ 0

第 3 条是这个项目能「编排」的前提：任意两段首尾相接都不跳帧，硬切就够，
不需要交叉淡化，也不用重做素材。

## 12. 合成动作：ffmpeg 的两个坑

用 `make_action.py` 拼接时：

- **解码要显式指定 `-c:v libvpx-vp9`**。ffmpeg 自带的 native vp9 解码器**不读 alpha 平面**，
  `alphaextract` 直接报 `Requested planes not available`。输入侧也要加，解出来才是 `yuva420p`。
- **`-auto-alt-ref 0`**。alt-ref 帧类型存不了 alpha，开了透明就没了。

完整参数：`-pix_fmt yuva420p -b:v 0 -crf 32`。

## 13. 验收为什么必须开真浏览器

`tsc` 抓不到黑底、错位、裁切、遮挡、动画时序。所以 `frontend/scripts/` 下全是 Playwright 脚本：

| 脚本 | 验什么 |
|---|---|
| `shot.mjs` | 桌面 + 手机截图，人眼看 |
| `verify-walk.mjs` | 跑动 + 摄像机跟随 |
| `verify-walk-timing.mjs` | 前 `leadSec` 秒几乎不动，之后才平移 |
| `verify-drag.mjs` | 拖拽跟手 + 背景到尽头 |
| `verify-hit.mjs` | 命中区贴角色本体（空地不再隔空抓人） |
| `verify-scenes.mjs` | 四个房间切换 |
| `verify-memes.mjs` | 27 张表情真的加载（`naturalWidth > 0`） |
| `verify-combo.mjs` | 编排动作：面板有它、点了能播、时长对得上 |

断言要能区分「产品真错」和「断言写错」。看到 FAIL 先定性，再动手。

## 14. 素材文件名为什么是编号

`anim/a001.webm`、`memes/m001.png`，名字只活在 `filename-map.json` 里。

中文文件名在打包、跨平台解压、URL 编码上都踩过坑（`cpSync` 会在 `unlink` 那步炸、
URL 还要 `encodeURIComponent`）。磁盘上只留编号，名字 ↔ 文件的对应关系集中在一张表里，
`gen_manifest.py` 读它填 `file` 字段。

**没登记的动作会被跳过并报错**，不会悄悄退回中文名 —— 宁可构建时吵，也不要线上 404。
